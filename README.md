# Mage__08 Software Center

A modern, high-performance Software Center built for Mage__08 to showcase and distribute desktop applications, web projects, and robot simulation tools.

## 🚀 Features

- **Automated GitHub Integration**: Fetches the latest releases, versions, update dates, and profile info directly via GitHub REST API.
- **Modern UI/UX**: Premium Dark Theme with Glassmorphism, Cyberpunk aesthetics, Neon glows, and smooth Micro-animations.
- **Theme Support**: Includes Dark, AMOLED, and Light themes. Saves user preference locally.
- **Command Palette**: Quick navigation and search feature using `Ctrl + K`.
- **Progressive Web App (PWA)**: Installable, offline support via Service Workers, and manifest configuration.
- **Performance Optimized**: Zero heavy frameworks. Built strictly with Vanilla HTML5, CSS3, and JavaScript ES6+. Lighthouse score optimized.
- **Fully Responsive**: Adapts seamlessly to Desktop, Tablet, and Mobile devices.
- **Easter Egg**: Includes a hidden developer mode unlocked via a secret key `120408`.

## 🛠️ Technologies Used

- **HTML5** (Semantic & Accessible)
- **CSS3** (Custom Properties, Flexbox, Grid, Animations, Glassmorphism)
- **JavaScript (ES6+)** (Fetch API, LocalStorage, IntersectionObserver, Service Workers)
- **Google Fonts** (Poppins & Inter)
- **Font Awesome 6** (Icons)

## 🚀 How to Deploy on GitHub Pages

This project requires **zero build tools** and **no configuration**. It is completely ready to be deployed.

1. **Create a Repository:**
   Create a new repository on your GitHub account (e.g., `magApp`).

2. **Upload Files:**
   Upload all the files in this folder (`index.html`, `style.css`, `app.js`, `manifest.json`, `sw.js`, `README.md`) to the main branch of your repository.

3. **Enable GitHub Pages:**
   - Go to your repository's **Settings**.
   - Navigate to the **Pages** section on the left sidebar.
   - Under **Source**, select the `main` branch (and `/root` folder).
   - Click **Save**.

4. **Done!**
   GitHub will provide you with a URL (e.g., `https://mage19vn.github.io/magApp/`). The website will go live in a few minutes.
